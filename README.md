# IT-INCUBATOR Todolist

Учебное приложение для управления списками задач, разработанное в рамках IT-INCUBATOR. Данные хранятся на сервере SamuraiJS API.

## Возможности

- Вход в аккаунт и выход из него.
- Создание, переименование и удаление списков задач.
- Добавление, редактирование и удаление задач, отметка выполнения.
- Фильтрация задач по статусу.
- Переключение светлой и тёмной темы.

## Технологии

React 19, TypeScript, Vite 7, Redux Toolkit и RTK Query, Material UI, React Hook Form, Zod, React Router и Axios.

## Локальный запуск

Требуются Node.js 22.12+ и установленный pnpm.

1. Скачайте проект или клонируйте репозиторий и откройте терминал в его корневой папке.
2. Установите зависимости:

   ```bash
   pnpm install
   ```

3. Создайте файл `.env` в корне проекта, рядом с `package.json`:

   ```dotenv
   VITE_API_KEY=your_api_key_here
   VITE_BASE_URL=https://social-network.samuraijs.com/api/1.1/
   ```

   Замените `your_api_key_here` своим API-ключом SamuraiJS. Для работы с сервисом требуется аккаунт и API-ключ. Ссылка на сервис для регистрации есть на экране входа. Пример выше содержит заглушку, а не рабочий ключ.

4. Запустите сервер разработки:

   ```bash
   pnpm dev
   ```

5. Откройте [http://127.0.0.1:3000](http://127.0.0.1:3000).

Если порт 3000 занят, запустите Vite напрямую на другом порту:

```bash
pnpm exec vite --port 3001
```

Приложение будет доступно по адресу [http://127.0.0.1:3001](http://127.0.0.1:3001). Автоматический выбор свободного порта отключён настройкой `strictPort`.

После изменения `.env` перезапустите сервер разработки.

## Подключение к API

В режиме разработки запросы идут на `/api/1.1/` через Vite proxy. Адрес сервера задан в `vite.config.ts`; `VITE_BASE_URL` в этом режиме не используется.

В production-сборке адрес API берётся из `VITE_BASE_URL`. Переменные окружения нужно задать до сборки. Локальный proxy не входит в собранное приложение: при размещении сайта необходимо учитывать правила CORS и проверку домена на стороне API.

## Команды

| Команда | Назначение |
| --- | --- |
| `pnpm dev` | Сервер разработки на порту 3000 |
| `pnpm exec vite --port 3001` | Сервер разработки на порту 3001 |
| `pnpm build` | Проверка TypeScript и сборка в `dist/` |
| `pnpm preview` | Локальный просмотр готовой сборки; предварительно выполните `pnpm build` |
| `pnpm test` | Запуск Vitest в режиме наблюдения; тестовые файлы пока не добавлены |

## Приватные данные и публикация

- `.env`, локальные файлы окружения, `node_modules/` и `dist/` исключены через `.gitignore`.
- `package.json` и `pnpm-lock.yaml` нужно хранить в репозитории для установки зависимостей.
- Не добавляйте личные пароли, токены и рабочие API-ключи в исходники, документацию и коммиты. Если создаёте `.env.example`, используйте только заглушки.
- `.gitignore` не удаляет файлы, уже отслеживаемые Git, и секреты из прошлых коммитов. Перед публикацией проверьте также историю репозитория.

**Переменные `VITE_*` доступны в браузере и попадают в клиентскую сборку.** Хранение ключа в `.env` предотвращает его случайное добавление в Git, но не делает его секретным для пользователей приложения. Ключи, которые должны оставаться конфиденциальными, необходимо хранить на сервере.
